# UI & UX Design Systems Skill

This skill defines the rules for crafting world-class, premium user interfaces that feel bespoke, purposeful, and authoritative.

## Visual Design Directives

1. **Brand Color Harmony**:
   - Establish a dominant brand primary (e.g. deep authoritative navy `#1b3d6f`), a high-utility secondary (e.g. clinical teal `#2e8fa8`), and crisp accents (e.g. WhatsApp green `#25d366`, verified emerald `#059669`).
   - Avoid pitch-black monolithic backgrounds; use soft radial gradients, slate tones, and gentle tint surfaces (`#f8fafc`, `#eaf7fa`).

2. **Rejection of Generic "Boxed" & One-Sided Border Patterns**:
   - Strictly prohibit isolated single-sided borders (`border-bottom` or `border-left` alone as a separator) that look unfinished.
   - Use unified, 4-sided modular containment cards (`border: 1px solid #e2e8f0; border-radius: 8px; box-shadow: 0 2px 12px rgba(15,41,74,.03)`).
   - In Shopify-style product specification areas, prefer unboxed hairline tables with clean key-value rows.

3. **High-Contrast Call-to-Action (CTA) Architecture**:
   - Dark background CTAs must NEVER have dark or faint buttons.
   - Primary action on dark navy: Solid crisp white button (`background: #ffffff; color: #1b3d6f !important; font-weight: 700;`).
   - WhatsApp action: Vibrant official green (`background: #25d366; color: #ffffff !important; font-weight: 700;`).
   - Secondary action: Frosted glass outline (`background: rgba(255,255,255,.08); color: #ffffff; border: 1px solid rgba(255,255,255,.3)`).
   - Anchor banners with a Live Status Pill (pulsating dot) and verified compliance metadata.

4. **Typography & Visual Rhythm**:
   - Pair an expressive, modern geometric heading font (`Sora`, `Inter`, `Outfit`) with a highly legible body font (`Plus Jakarta Sans`).
   - Apply micro-kickers (`.eyebrow`) with tracked uppercase text (`letter-spacing: .12em; font-size: 10px; font-weight: 700;`) to guide the reader.
   - Keep paragraph line lengths optimal (50–75 characters per line).
